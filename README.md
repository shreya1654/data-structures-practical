## Purpose

This repository documents my practical programming exercises and helps me practise fundamental data structures, searching, sorting, and algorithm implementation in C.

## How to Run

Compile a program using a C compiler such as GCC:

```bash
gcc binary_search.c -o binary_search
```

Run it on Windows:

```powershell
.\binary_search.exe
```

Replace `binary_search.c` with the desired source filename to compile another program.
